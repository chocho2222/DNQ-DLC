# DNQ-DLC v0.1.0-rc.1

Private release candidate for the DNQ-DLC paper artefact.

## Included

- DNQ-DLC and comparator implementations;
- self-trained DNQ-DLC, DLC and RL checkpoints;
- frozen 200-case matched primary-endpoint source data and statistics;
- four-checkpoint DLC-JTO sensitivity results;
- editable publication figures, source tables and 22 simulation videos;
- GitHub Pages-ready evidence site;
- model/data cards, licences, provenance boundaries and SHA-256 manifests.

## Primary result

DNQ-DLC completed at least one overtake in 171/200 matched cases (85.5%),
compared with 143/200 (71.5%) for Rule Expert. The paired difference was
+14.0 percentage points (95% paired bootstrap CI 6.5 to 21.5; two-sided exact
McNemar p = 0.000617).

## Release-candidate boundary

This draft is private and non-citable. Final author metadata, public track/media
clearance, archival DOI and manuscript links will be added at `v0.1.0`.
