# Public release checklist

- [ ] Insert author names, affiliations, ORCID identifiers, and contact email.
- [ ] Complete the custom-track and rendered-media public-release review.
- [ ] Convert `CITATION.cff.template` to a valid `CITATION.cff`.
- [x] Create and push the private author-owned GitHub repository.
- [x] Verify CI, repository settings, relative links and release manifests.
- [x] Create the private `v0.1.0-rc.1` draft Release.
- [ ] After manuscript submission, change repository visibility to public.
- [ ] Enable the prepared GitHub Pages deployment and record its URL.
- [ ] Publish the frozen `v0.1.0` GitHub Release and record its commit hash.
- [ ] Archive the release with Zenodo or an equivalent service and record the DOI.
- [ ] Replace manuscript repository, Pages, release-tag, commit and DOI placeholders.
- [ ] Run the final primary-endpoint and closed-loop reproduction checks.
- [ ] Verify that every excluded item in `ASSET_LICENSES.md` is cleared or removed.
