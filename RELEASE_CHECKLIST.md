# Public release checklist

- Insert author names, affiliations, ORCID identifiers, and contact email.
- Complete the custom-track and rendered-media public-release review.
- Convert `CITATION.cff.template` to a valid `CITATION.cff` with final metadata.
- Create the private author-owned GitHub repository.
- Enable GitHub Pages from docs/ and verify relative links.
- Create a versioned GitHub Release and record the commit hash.
- Archive the release with Zenodo or an equivalent service and record the DOI.
- Replace all manuscript repository, Pages, release-tag, commit, and DOI placeholders.
- Run the primary endpoint script and one closed-loop reproduction case.
- Verify that every excluded item in `ASSET_LICENSES.md` is cleared or removed.
